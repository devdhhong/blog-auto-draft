시작하기

프리셋·계정 정보를 저장할 구글 드라이브 폴더를 정해주세요. 윈도우와 맥에서 같은 폴더를 고르면 자동으로 동기화돼요.

동기화 폴더

이 컴퓨터에서 구글 드라이브 폴더를 찾지 못했어요. 구글 드라이브 데스크톱 앱을 설치하고 로그인하면 '내 드라이브' 폴더가 생겨요. 설치 후 [폴더 선택]으로 그 폴더를 골라 주세요. (drive.google.com 웹 주소는 쓸 수 없어요)

동기화 비밀번호

계정 비밀번호와 API 키를 암호화하는 비밀번호예요. 다른 컴퓨터에서도 이 비밀번호를 한 번 입력해야 해요. 잊어버리면 복구할 수 없어요.

설정

Gemini API 키 (무료)

aistudio.google.com/apikey 에서 구글 계정으로 로그인 → "API 키 만들기". 카드 등록 없이 무료 등급으로 쓸 수 있어요(하루 사용량 제한 있음). 무료 등급은 입력한 원고가 구글 모델 개선에 쓰일 수 있어요.
