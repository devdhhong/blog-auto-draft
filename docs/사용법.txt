블로그 자동 임시저장 - 사용법
=================================

원고(hwpx/txt)만 넣으면
  업체 프리셋대로 AI 꾸밈 → 해시태그 → 네이버 로그인 → 글 작성 → 태그 등록 → 임시저장
까지 자동으로 합니다. 발행은 직접 확인하고 해주세요.

[처음 한 번만 할 일]
1. 구글 드라이브 데스크톱 앱이 윈도우·맥 모두에 설치되어 있어야 합니다.
2. 프로그램 실행
   - 윈도우: BlogAutoDraft.exe 실행
     ("PC 보호" 경고가 뜨면 '추가 정보' → '실행')
   - 맥: '블로그 자동 임시저장.app'을 응용 프로그램 폴더로 옮긴 뒤 실행
     ("확인되지 않은 개발자" 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 '그래도 열기')
     ("손상되었기 때문에 열 수 없습니다"가 뜨면 터미널을 열고 아래 한 줄을 붙여넣고 엔터 후 다시 실행)
        xattr -cr "/Applications/블로그 자동 임시저장.app"
     - 맥에는 Google Chrome(또는 Microsoft Edge)이 설치되어 있어야 합니다.
     - 애플 실리콘(M1~M4) 맥은 mac-apple-silicon, 인텔 맥은 mac-intel 파일을 받으세요.
3. 처음 화면에서 동기화 폴더를 고릅니다 (구글 드라이브 '내 드라이브' 안의 NaverBlogHelper 폴더가 자동으로 잡힙니다).
   - 첫 컴퓨터: '동기화 비밀번호'를 정합니다.
     그다음 [프리셋 파일 가져오기]로 프리셋 파일(.json)을 넣으면 업체 프리셋이 한 번에 들어갑니다.
   - 두 번째 컴퓨터: 같은 폴더를 고르고 같은 동기화 비밀번호를 입력하면 프리셋·계정이 그대로 보입니다.
   - 동기화 비밀번호는 계정 비밀번호와 API 키를 암호화하는 데 쓰입니다. 잊어버리면 복구할 수 없습니다.
4. ⚙ 설정 → Gemini API 키 입력 (무료)
   - https://aistudio.google.com/apikey 에서 구글 계정으로 로그인 → 'API 키 만들기' → 복사해서 붙여넣기
   - 무료 등급은 하루 사용량 제한이 있고, 입력한 원고가 구글의 모델 개선에 쓰일 수 있습니다.
5. 업체 프리셋마다 네이버 아이디/비밀번호(+ 블로그 주소 아이디가 다르면 그것도)를 넣고 [저장].

[매일 쓰는 방법]
1. 프리셋(업체) 선택
2. 원고 파일(.hwpx/.txt)을 끌어다 놓기 (여러 개 가능)
3. [▶ 실행]
   - 네이버 작업용 브라우저(Edge/Chrome)가 열리고 자동으로 진행됩니다. 작업 중에는 그 창을 건드리지 마세요.
   - 처음 로그인할 때 자동입력 방지 문자/새 기기 인증이 나오면 그 창에서 직접 처리하면 이어서 진행합니다.
     (계정별로 로그인 상태가 저장되어 다음부터는 보통 건너뜁니다)
   - '업로드 전에 미리보기로 확인' 을 켜면 AI 꾸밈 결과를 보고 원고마다 [이 원고 업로드]를 눌러 올립니다.
4. 네이버 블로그 글쓰기 화면의 임시저장 목록에서 확인 후 발행하세요.

[원고 형식] 기존 웹 도구와 같습니다
- 첫 번호 줄(1, 2 ... 처럼 숫자만 있는 줄) 위쪽은 '상단 정보'로 보고 본문에 넣지 않습니다.
  상단 정보에 '제목: ...' 줄이 있으면 그게 글 제목이 됩니다. 없으면 상단 첫 줄(키워드 줄 제외), 그것도 없으면 파일 이름.
- 원고에 #해시태그가 3개 이상 있으면 그대로 쓰고, 없으면 AI가 만듭니다.
- 자동 인용구처리 문자(<, >)로 시작하는 줄은 인용구, (표) 다음 줄은 인용구 처리 등 기존 규칙 그대로입니다.
- hwpx의 볼드·밑줄 서식도 그대로 반영됩니다. 구버전 .hwp는 한글에서 hwpx로 다시 저장해 주세요.

[프리셋 파일]
- [프리셋 파일 가져오기]: 기존 웹 도구의 프리셋 파일이나 이 프로그램에서 내보낸 파일을 넣습니다.
  같은 이름이 있으면 덮어쓸지 물어보고, 저장된 네이버 계정은 그대로 유지됩니다.
- [내보내기]: 스타일·특이사항·메모만 파일로 저장합니다 (계정 정보는 들어가지 않음).
- 프리셋은 프로그램 안이 아니라 구글 드라이브 동기화 파일에만 저장됩니다.

[윈도우·맥 동기화]
- 프리셋, 계정, 설정은 구글 드라이브의 NaverBlogHelper/data.json 하나에 저장되어 두 컴퓨터가 같이 씁니다.
  한쪽에서 저장하면 다른 쪽에도 20초 안에 반영됩니다(구글 드라이브 동기화 시간 포함).
- 프로그램 버전은 GitHub에서 윈도우·맥이 같은 코드로 함께 만들어집니다. 새 버전이 나오면 화면 위에 알림이 뜹니다.

[잘 안 될 때]
- 실패하면 진행 기록에 이유가 나오고, 그 순간 화면이 '로그 폴더'에 사진으로 저장됩니다.
- 네이버 화면이 바뀌어 버튼을 못 찾을 때는 구글 드라이브 NaverBlogHelper 폴더에 selectors.json을 만들어
  바뀐 항목만 적으면 두 컴퓨터 모두에 바로 적용됩니다. (로그 사진을 보내주시면 고칠 내용을 알려드릴 수 있어요)
- AI 오류(429)가 나면 무료 사용량을 잠시 초과한 것이니 1~2분 뒤 다시 [▶ 실행]하세요.

[주의]
- 짧은 시간에 많은 글을 연속으로 올리면 네이버가 자동화로 판단해 보호조치를 할 수 있습니다. 적당히 나눠서 쓰세요.
