📄 여기에 .txt, .hwpx, .hwp 파일을 끌어다 놓거나 클릭해서 선택

AI가 고른 인용구·배경색·강조는 미리보기에만 적용돼요. 입력한 원고 글자는 바뀌지 않아요. 원고를 수정하면 AI 강조는 자동으로 지워져요.

한글(.hwpx) 파일을 올리면 파일에 이미 되어있는 볼드·밑줄 서식을 그대로 읽어와서 "블로그" 형식 미리보기에 바로 적용해요(AI 실행 없이). .txt 파일은 글자 내용만 그대로 불러와요. 구버전 .hwp 파일도 글자 내용은 불러오지만(서식 없이), 표·이미지·각주 등이 있으면 순서가 꼬이거나 일부가 빠질 수 있어요 — 확인 후 이상하면 한글에서 "다른 이름으로 저장 > hwpx"로 바꿔서 다시 올려주세요.

붙여넣기로 폰트·인용구 박스가 안 먹힐 때 쓰는 방법이에요: ① 위 "HTML 코드 복사" 클릭 → ② 네이버 에디터에서 글 쓸 위치를 한 번 클릭해서 커서를 둔다 → ③ 개발자도구(F12 또는 우클릭 → 검사) Console 탭을 열고 아래처럼 입력 후 Enter:
